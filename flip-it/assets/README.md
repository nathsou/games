# Flip it card art

`cards.png` is the original generated six-face prototype atlas, retained with its prompt for provenance. The current cards use code-native HTML numerals over geometric color bands: the upright active number and upside-down alternate number are the main artwork. The runtime no longer loads the atlas. Rank 10 uses adjusted spacing so both digits remain readable at phone sizes.

Balatro supplied the requested broad visual inspiration. No existing game sprites, logos, fonts or card artwork were imported.

## Exact generation prompt

Use case: stylized-concept
Asset type: production sprite atlas of six illustrated playing-card faces for an original browser card game, Flip it.
Primary request: original retro pixel-art playing cards with the tactile, vibrant late-night casino feel of Balatro, without reproducing any existing game artwork, logos, jokers or card designs.
Composition: exactly THREE equal columns and TWO equal rows in a square image, no gutters, each tile a complete upright portrait card of aspect ratio 2:3 filling its tile. Every tile has the same ivory parchment frame, squared pixel corners, distressed ink edges, and dark teal shadow. Card interiors are burgundy, petrol teal, plum and midnight blue with warm gold and coral accents. Keep the upper 20% and lower 20% of every card light, quiet and empty so game code can overlay readable numeric ranks. No numbers or lettering anywhere.
Subject: a different original central pixel emblem in each tile, left-to-right top row: a coral flame, a golden crescent moon, a teal comet; bottom row: a purple eye, a red lightning bolt, a golden eight-point star. Small ornamental pixels surround each emblem with carefully restrained sparkle and halftone texture. Emblems should occupy the middle third, not the blank rank zones.
Style: crisp chunky 16-bit sprite art, limited palette, visibly stepped edges, subtle dither texture, handmade print character, bold silhouettes legible at 90px card width. Flat front views, no perspective, no photographs, no hands, no table, no marketing layout. All six cards fully visible, precisely aligned, identical size and borders, no margins outside the 3x2 grid.
Constraints: original assets only. No text, numerals, brands, suits, watermark, characters, copied Balatro sprites, or extra tiles.
