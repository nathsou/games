# Retro design directions

Four generated visual proposals for choosing Flip It's next visual direction. Each includes a full table and enlarged card-front, starred-card, card-back and selection samples. These are design mockups; the existing game's rules and state remain authoritative during implementation.

| Direction | Interface | Cards |
| --- | --- | --- |
| [A · Velvet Arcade](a-velvet-arcade.png) | Emerald felt, oxblood accents, fine gold frames | Ivory paper, pixel numerals, ornate arrow backs |
| [B · Seventies Parlour](b-seventies-parlour.png) | Warm brown, cream panels, editorial serif labels | Bold slab numerals, ochre/orange/green arches, geometric printed backs |
| [C · Pocket Console](c-pocket-console.png) | Sage LCD palette, neutral panels, raspberry accents | Pixel corners, monochrome ranks, tiled arrow backs |
| [D · Midnight Arcade](d-midnight-arcade.png) | Ink navy, fine borders, muted teal and coral | Ivory faces, crisp retro numbers, patterned arrow medallion backs |

D is recommended for its restrained interface and readable cards. The player may choose a different direction or combine one direction's interface with another's cards.

## Implementation requirements

- Retain the arrow logo, starred opener, 2–5 players, 1–5 round-wins setting and bot/shared-device choices in table settings.
- Preserve right-first double turns and the single play space in Quick turns.
- Keep exposed opponent cards fully readable with both ranks, exact duplicates and the enlarged composition inspector.
- Keep the hand, controls and populated table within the laptop viewport; retain phone layouts and accessible keyboard/touch controls.
- Preserve multi-card drag previews, per-card action animations, chat/reactions, online invitations/reconnection, action logs, highlights and browser replays.
- Use clear game labels and restrained decoration without aspirational filler copy.
- Implement the chosen direction using scalable components and assets. Do not use a generated mockup as the application background or replace live controls with image text.
