# Artwork provenance

These six original portrait atlases were generated with the built-in ImageGen tool on 3 October 2026. The tool exposes no model selector, so a specific image model version cannot be verified. No commercial Similo or Balatro artwork was used.

Each atlas has six columns and four rows. Card names and framing are drawn by Canvas, rather than baked into the images. The renderer crops each cell proportionally; the atlas dimensions may differ between outputs. Historical and mythological portraits are stylized interpretations, not documentary likenesses.
