# Self-hosted typography

DM Mono (400 and 500) and Martian Mono (400 and 500), downloaded from the Google Fonts stylesheet on 2026-10-03. These fonts are served locally; the app makes no font requests to Google or a CDN.

Source families: https://fonts.google.com/specimen/DM+Mono and https://fonts.google.com/specimen/Martian+Mono.

SIL Open Font License files are included as `OFL-dmmono.txt` and `OFL-martianmono.txt`, from the corresponding families in https://github.com/google/fonts/tree/main/ofl.
